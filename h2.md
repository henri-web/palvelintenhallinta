### Sudo without password (Karvinen)

-Kuinka luodaan käyttäjiä, jotka voivat käyttää sudoa ilman salasanaa

-Aloita luomalla uusi käyttäjä ja lisää hänet tekemääsi ryhmään

 ```
sudo adduser antero
sudo groupadd sudoless
sudo adduser antero sudoless
```
-Tässä tapa korjata sudo virheitä

`sudo -i`

-Tehdään sääntö sudoless ryhmälle, joka antaa heidän käyttää sudoa ilman salasanaa

```
sudo visudo /etc/sudoers.d/sudoless
%sudoless All = (ALL) NOPASSWD: ALL
```

-Muistetaan aina testata, jos et ole testannut mitään ei ole tehty

```
ssh antero@localhost
sudo -k
sudo echo "See ypu at Terokarvinen.com"
See you at TeroKarvinen.com
```

### Passwordless Sudo with Ansible (Karvinen)

Sudo ilman salasanaa automatisointi, ensin suoritetaan yllä oleva esimerkki.

Testataan ensin ilman sudo salasalattomuutta

Mennään puun site.yml kohtaan ja 

```
-hosts: all
 become: true
 roles:
  - world
  - antero
```

Nyt tehdään tämä 

`ansible-playbook site.yml --ask-become-password`


### Ansible Doc

copy = kopioi tiedoston tai hakemiston etäkoneelta tai paikalliselta koneelta etäkoneelle.

- content = määrittää tarkkaan mitä kopioidaan, toimii vain jos dest on tiedosto

- src = määrittää mistä kopioitava sisältö tulee

- owner,group,mode = kopioidun tiedoston omistaja,ryhmä ja oikeudet

```
  ansible.builtin.copy:
    src: files/esimerkki.esim
    dest: /etc/esimerkki/esimerkki.esim
    owner: root
    group: root
    mode: '0644'
```

apt = hallitsee debianin paketteja (asennus,poisto,päivitys) 

- name = listaa pakettejen nimet, jolla valitset minkä haluat käsiteltäväksi

- state = määrittää paketin tilan järjestelmässä

- update_cache = suoritetaanko `apt-get update` ennen toimenpiteitä'

esimerkki

  ```
ansible.builtin.apt:
  name: esimerkki
  state: latest
  update_cache: yes

  ```

file = käytetään tiedostoje ja hakemistojen luomiseen, poistamiseen ja niiden oikeuksien hallintaan

 - path = tiedoston tai hakemiston polku kohdepalvelimelle

 -  recurse = määrittää annettujen oikeuksien asennuksen rekursiivisesti kaikille hakemiston sisällä oleville tiedostoille ja alihakemistoille.

 -  src = määrittää lähdepolun, johon viitataan

 -  state = määrittää mitä kohteelle tehdään tai millainen sen tilan pitäisi olla

 -  owner,group ja mode = omistaja, ryhmän nimi ja käyttöoikeudet.

uuden hakemiston luominen `file` moduulilla

```
ansible.builtin.file:
  path: /etc/esimerkki
  state: directory
  owner: root
  group: root
  mode: '0755'
```

user = käytetään käyttäjätilien luomiseen, muokkaamiseen ja poistamiseen.

- name = käyttäjätunnus, jota muokataan, poistetaan ja luodaan

- create_home = luodaanko käyttäjälle kotihakemisto

- comment = käyttäjän kuvaus tai kokonimi

- groups = lista ryhmistä, joihin käyttäjä liitetään.

- shell = käyttäjän  oletuskomentotulkki

- state (present/absent) = present: varmistaa että käyttäjä on olemassa, absent: poistaa käyttäjätilin järjestelmästä

Käyttäjän luominen ryhmäjäsenyydellä

```
ansible.builtin.user:
  name: esi
  comment: "esimerkki"
  shell: /bin/bash
  create_home: yes
  groups: sudo,docker
  append: yes
  state: present
```

authorized_key = käytetään ssh-avainten hallintaan järjestelmän käyttäjätileillä

 user = sen käyttäjän tunnus kenen hakemistoon avain lisätään tai poistetaan

 key = itse avaimen merkkijono

 Esimerkki lisätään käyttäjälle esimerkki ssh-avain järjestelmään

 ```
ansible.builtin.authorized_key:
  user: matti
  key: sjoåosdjådsåkåskcåskc
  state: present
  exclusive: no
```
